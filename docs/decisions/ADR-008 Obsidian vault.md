# ADR-008 Obsidian vault in docs/

**Decision:** docs/ in the repo is the Obsidian vault for plans, the ledger, ADRs and session notes. .obsidian/workspace*.json is gitignored.

**Why:** Planning notes are versioned with the code and every Claude session can read them.
