# ISO 20022 Learning Site

A static, interactive site that teaches ISO 20022 (pacs.008 first) to new bank staff. It is a personal, public project.

- [[Project Plan]]: stack, data model, phases, risks, maintenance
- [[Ledger]]: tasks for me (#me) and for agents (#agent)
- [[sources]]: public sources used for content, with retrieval dates
- [[maintenance]]: yearly ISO/Swift update routine
- Decisions: `decisions/` (ADR notes)
- Session logs: `sessions/`

**For Claude sessions:** run `/next-phase` (it reads this note, [[Ledger]] and the newest session note) and end with `/session-wrap`. Rules: `CLAUDE.md` and [[ADR-020 Delegated merging and session loop]].
